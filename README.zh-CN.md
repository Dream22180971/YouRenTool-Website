## ⚡ 5 分钟快速开始

```bash
git clone https://github.com/Dream22180971/YouRenTool-Website.git
cd YouRenTool-Website

python -m http.server 8080
```

访问 `http://localhost:8080`。

主站以静态页面为主，基础本地预览不需要复杂前端构建链。
